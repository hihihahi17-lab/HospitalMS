# Hospital Management System

## Description
Hospital Management System est une application console développée en Java dans le cadre du module de Programmation Orientée Objet (POO).

Cette application permet de gérer :
- les patients
- les médecins
- les rendez-vous
- les dossiers médicaux

Le projet respecte les principes fondamentaux de la programmation orientée objet ainsi qu’une architecture modulaire claire.

---

## Objectifs du projet

Ce projet permet de mettre en pratique :

- l’encapsulation
- l’héritage
- le polymorphisme
- les interfaces et classes abstraites
- les exceptions personnalisées
- les collections Java
- la persistance des données
- l’organisation modulaire d’un projet Java

---

## Fonctionnalités

### Gestion des patients
- Ajouter un patient
- Modifier un patient
- Supprimer un patient
- Afficher les patients

### Gestion des médecins
- Ajouter un médecin
- Modifier un médecin
- Supprimer un médecin
- Afficher les médecins

### Gestion des rendez-vous
- Créer un rendez-vous
- Supprimer un rendez-vous
- Afficher les rendez-vous

### Persistance des données
- Sauvegarde des données dans des fichiers texte ou CSV
